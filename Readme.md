# Developers Night – Team Projects Repository 🚀

Welcome to the **Developers Night** team submissions repository.

All teams are required to push their projects into this **single repository**, following the structure and naming conventions mentioned below.

---

## 📁 Repository Structure

Each team must create **one folder** for their project using the format:

<Team_ID_Team_Name>

## 📦 Inside Your Team Folder

Each team folder should contain:

A Readme.md file and Zip Folder of the project.

### Team README.md should include:
- Project Title
- Team Members
- Problem Statement
- Solution Overview
- Tech Stack Used
- How to Run the Project (if applicable)

## 📌 Submission Instructions

1. **Fork** this repository to your GitHub account
2. Clone your forked repository
3. Create your team folder using the format:
4. Zip the **root of your project** and name it clearly:
5. Upload the ZIP file inside your team folder
6. Commit your changes with a meaningful message
7. Create a **Pull Request (PR)** to the `main` branch of this repository

## ⛔ Important Rules

- ❌ Do NOT create separate repositories
- ❌ Do NOT modify or delete other teams’ folders
- ❌ Do NOT push unnecessary files (node_modules, build folders, etc.)

- ✅ Push **only your team folder**
- ✅ Follow proper naming conventions
- ✅ Keep commits clean and meaningful
